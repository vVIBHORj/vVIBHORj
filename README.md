```text
 WhatsApp export
       │
 ┌─────▼─────┐   ┌───────────┐   ┌──────────────┐   ┌────────────┐   ┌──────────────┐
 │ ingestion │──▶│  storage  │──▶│ orchestration│──▶│ evaluation │──▶│ presentation │
 └───────────┘   └───────────┘   └──────┬───────┘   └─────┬──────┘   └──────────────┘
                                        │                 │
                       hybrid retrieval + timestamp-      citation validity on
                       aware context expansion            every answer
```

| | |
|---|---|
| **Engineering** | Turns WhatsApp exports into a semantic Q&A system over a five-layer architecture. Hybrid retrieval plus timestamp-aware context expansion handles short, elliptical replies ("ok", "same", "that one") that plain vector search loses. Query routing is deterministic. |
| **Evaluation** | Benchmarked across 12 conversational phenomena with strict citation checks, backed by a full test suite. v1 ([ChatLens-RAG](https://github.com/vVIBHORj/ChatLens-RAG)) was a local CRAG loop where an LLM grader rewrites weak retrievals and a second pass checks groundedness. |
| **Product** | 100% offline, zero API cost, no data leaves the device. Analytics (sentiment, response time, engagement) stay in deterministic Pandas, decoupled from the LLM. |

</details>

```text
prompt ─┬─▶ quality predictor ─▶ Qwen3 · small   $
        ├─▶ quality predictor ─▶ Qwen3 · medium  $$
        └─▶ quality predictor ─▶ Qwen3 · large   $$$

                     └─▶ cheapest tier that clears the quality bar
```

| | |
|---|---|
| **Engineering** | Routes prompts across a 3-tier Qwen3 pool using per-model quality predictors trained on a ~2,000-prompt benchmark (reasoning, coding, factuality). |
| **Data** | An outcome-matrix pipeline logs quality, tokens, latency and cost into a versioned DuckDB/Parquet telemetry store. |
| **Product** | Benchmarked against fixed-tier, heuristic and TF-IDF routers. The question it answers: which model is worth it for this prompt? |

      ·   ✦        ·         target

**swarm-uav-tracking-mappo** · Cooperative multi-target tracking with drones. CTDE setup with a 39-D actor and 28-D critic, built on the Anti-UAV-RGBT setting. Runs at 535 FPS on a consumer laptop and beats heuristic baselines on coverage, collision safety and occlusion resilience, with automated tests and benchmarks.

**SWARMFORGE** · A swarm and intercept simulator where autonomous drones prioritize threats and protect high-value assets. GPU physics in PyTorch, continuous closest-point-of-approach anti-tunneling, Kalman tracking, procedural scenarios and a real-time 3D tactical viewer. Tuned to run on consumer hardware.
